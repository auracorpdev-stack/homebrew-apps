# Auraco Homebrew Apps

Install Auraco apps with Homebrew:

```sh
brew tap auracorpdev-stack/apps
brew install --cask dynamichorizon
brew install --cask backspace
```

## DynamicHorizon

DynamicHorizon turns the area around the Mac camera into an interactive part of macOS.

Website: https://www.dynamichorizon.app

## Backspace

Backspace brings cinematic live wallpapers to the Mac Desktop and Lock Screen.

Website: https://www.backspacemac.app
